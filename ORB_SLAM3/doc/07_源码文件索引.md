## 7.8 建议阅读顺序

1. `System.h/cc` — 建立全局图景  
2. `Tracking.h` + `Track()` — 前端状态机  
3. `Frame` / `KeyFrame` / `MapPoint` / `Map` / `Atlas` — 数据结构  
4. `LocalMapping::Run()` — 建图与 IMU 初始化  
5. `LoopClosing::Run()` — 回环与融合  
6. `ImuTypes` + `Optimizer` + `G2oTypes` — 后端细节  
7. `ORBextractor` / `ORBmatcher` / `CameraModels` — 前端几何  
8. 任意一个 `Examples/*/*.cc` — 工程接入方式  

## 7.9 源码规模参考（便于定位）

| 文件 | 特点 |
|------|------|
| `src/Tracking.cc` | 前端逻辑最长之一 |
| `src/LocalMapping.cc` | 建图 + IMU 初始化 |
| `src/LoopClosing.cc` | 回环/融合逻辑复杂 |
| `src/Optimizer.cc` | 体量最大，集中各类优化 |
| `src/Frame.cc` / `KeyFrame.cc` | 数据结构与序列化较全 |

阅读时优先对照头文件公开接口，再下钻对应 `.cc` 中的 `Run`/`Track` 主函数。
