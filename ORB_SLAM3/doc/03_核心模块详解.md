# 03 核心模块详解

## 3.1 Tracking（前端跟踪）

文件：`include/Tracking.h`，`src/Tracking.cc`

### 状态机

```cpp
enum eTrackingState {
    SYSTEM_NOT_READY = -1,
    NO_IMAGES_YET = 0,
    NOT_INITIALIZED = 1,
    OK = 2,
    RECENTLY_LOST = 3,
    LOST = 4,
    OK_KLT = 5
};
```

### 输入接口

| 方法 | 说明 |
|------|------|
| `GrabImageStereo` | 双目：特征 + 立体匹配 → `Track()` |
| `GrabImageRGBD` | RGB-D：深度关联 → `Track()` |
| `GrabImageMonocular` | 单目 → `Track()` |
| `GrabImuData` | 缓存 IMU 到 `mlQueueImuData` |

### `Track()` 主流程（概念）

1. 时间戳合理性 / IMU 异常检查（可能 reset 或新建地图）
2. 若有 IMU：`PreintegrateIMU()`
3. `NOT_INITIALIZED`：`StereoInitialization()` 或 `MonocularInitialization()`
4. 位姿预测：
   - `TrackWithMotionModel()` 或 `TrackReferenceKeyFrame()`
   - 失败 → `RECENTLY_LOST`：IMU 用 `PredictStateIMU()`，视觉尝试 `Relocalization()`
   - 进入 `LOST`：reset 或 `CreateMapInAtlas()`
5. `TrackLocalMap()`：更新局部地图 → 投影匹配 → 位姿优化
6. `NeedNewKeyFrame()` → `CreateNewKeyFrame()`
7. 记录相对位姿列表，供轨迹导出

### 位姿优化选择

- 纯视觉：`Optimizer::PoseOptimization(Frame*)`
- 视觉惯性：`PoseInertialOptimizationLastFrame` / `PoseInertialOptimizationLastKeyFrame`

### 局部地图

- `UpdateLocalKeyFrames()` / `UpdateLocalPoints()`
- `SearchLocalPoints()`：`ORBmatcher::SearchByProjection`
- 参考关键帧 `mpReferenceKF`、局部 KF/MP 向量

### 其他重要 API

| 方法 | 作用 |
|------|------|
| `InformOnlyTracking` | 纯定位模式 |
| `CreateMapInAtlas` | 新建地图 |
| `UpdateFrameIMU` | IMU 初始化/尺度更新后刷新帧状态 |
| `ParseCam/ORB/IMUParamFile` | Legacy YAML 解析 |
| `newParameterLoader` | 新 `Settings` 加载 |

## 3.2 LocalMapping（局部建图）

文件：`include/LocalMapping.h`，`src/LocalMapping.cc`

### `Run()` 循环

```text
SetAcceptKeyFrames(false)
if CheckNewKeyFrames:
    ProcessNewKeyFrame()       # BoW、插入地图、更新共视
    MapPointCulling()          # 剔除劣质新点
    CreateNewMapPoints()       # 邻域三角化
    if 队列空: SearchInNeighbors()   # 投影融合 Fuse
    LocalBA / LocalInertialBA
    InitializeIMU（分阶段）
    KeyFrameCulling()
    ScaleRefinement（单目惯性窗口）
    LoopCloser->InsertKeyFrame()
SetAcceptKeyFrames(true)
```

### 同步 API

- `InsertKeyFrame` / `EmptyQueue` / `AcceptKeyFrames` / `InterruptBA`
- `RequestStop` / `RequestReset` / `RequestResetActiveMap` / `RequestFinish`
- `IsInitializing` / `GetCurrKF`

### IMU 分阶段（`mTinit` 累积有效运动时间）

| 阶段 | 大致时机 | 行为 |
|------|----------|------|
| 首次初始化 | 满足运动条件后 | `InitializeIMU(priorG, priorA, true)` |
| VIBA1 | ~5s | `SetIniertialBA1` + 再优化 |
| VIBA2 | ~15s | `SetIniertialBA2`，弱化/去掉 prior |
| ScaleRefinement | ~25/35/45…s | 单目且 KF 数量受限时精炼尺度 |

内部调用链概念：`Optimizer::InertialOptimization` → `Map::ApplyScaledRotation` → `Tracking::UpdateFrameIMU`。

## 3.3 LoopClosing（回环与融合）

文件：`include/LoopClosing.h`，`src/LoopClosing.cc`

### `Run()` 逻辑

1. `NewDetectCommonRegions()`：BoW + Sim3 精炼
2. 若 `mbMergeDetected`：`MergeLocal()`（视觉）或 `MergeLocal2()`（惯性）
3. 若 `mbLoopDetected`：几何校验后 `CorrectLoop()`
4. `CorrectLoop` 后可启动 `RunGlobalBundleAdjustment`

### 地点识别

- 数据库：`KeyFrameDatabase::DetectNBestCandidates`
  - 同地图候选 → Loop
  - 异地图候选 → Merge
- `DetectCommonRegionsFromBoW` → Sim3（`OptimizeSim3` / RANSAC）
- 连续 coincidence（通常 ≥3）确认
- 投影匹配：`FindMatchesByProjection`、`DetectAndReffineSim3FromLastKF`

### CorrectLoop

- Essential Graph：`OptimizeEssentialGraph` 或惯性 `OptimizeEssentialGraph4DoF`
- `SearchAndFuse` 融合重复地图点
- 异步 Full BA / FullInertialBA

### Merge

- 估计 `mSold_new`（Sim3）；惯性模式常限制 scale ∈ [0.9, 1.1]，可强制 yaw-only
- Welding BA：`LocalBundleAdjustment` / `MergeInertialBA`
- 合并 KF/MP 到活动地图，`Atlas::ChangeMap`，旧地图标记 bad

可通过 YAML / 构造参数控制 `mbActiveLC`（loopClosing 开关）。

## 3.4 特征提取与匹配

### ORBextractor

文件：`ORBextractor.h/.cc`

- 构造参数：`nfeatures, scaleFactor, nlevels, iniThFAST, minThFAST`
- `operator()(image, mask, keypoints, descriptors, vLappingArea)`
- 流程：图像金字塔 → OctTree 均匀 FAST → 描述子
- 鱼眼双目用 `vLappingArea` 标记重叠区域

单目初始化阶段使用 `mpIniORBextractor`（通常提取更多特征）。

### ORBmatcher

文件：`ORBmatcher.h/.cc`

| 方法 | 用途 |
|------|------|
| `DescriptorDistance` | Hamming 距离 |
| `SearchByProjection` | 跟踪/重定位/回环投影匹配 |
| `SearchByBoW` | 帧–KF / KF–KF 词袋匹配 |
| `SearchForInitialization` | 单目初始化 |
| `SearchForTriangulation` | 三角化候选（含极线约束） |
| `SearchBySim3` | Sim3 下匹配 |
| `Fuse` | 地图点融合去重 |

参数：`nnratio`、方向一致性检查、`TH_LOW` / `TH_HIGH`。

### Frame 内深度/立体

- 矫正双目：`ComputeStereoMatches()`
- RGB-D：`ComputeStereoFromRGBD()`
- 鱼眼双目：`ComputeStereoFishEyeMatches()`（BFMatcher）
