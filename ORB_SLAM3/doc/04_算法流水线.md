# 04 算法流水线

本章按运行时顺序描述主要算法路径，对应源码调用关系。

## 4.1 双目 / RGB-D 初始化

入口：`Tracking::StereoInitialization()`

```text
当前 Frame 有足够特征与深度/视差
  → 创建首个 KeyFrame
  → 对有效深度点直接生成 MapPoint（度量尺度）
  → 插入 LocalMapping
  → 状态 → OK
```

特点：单帧即可初始化；近点可单帧插入，远点通常需双关键帧确认（`mThDepth`）。

## 4.2 单目初始化

入口：`Tracking::MonocularInitialization()` → `CreateInitialMapMonocular()`

```text
首帧：提取较多 ORB，缓存为 InitialFrame
后续帧：SearchForInitialization（光流/匹配）
  → GeometricCamera::ReconstructWithTwoViews（或 TwoViewReconstruction）
  → 三角化得到初始 3D 点
  → CreateInitialMapMonocular
  → Global BA
  → 以中值深度归一化尺度
  → 状态 → OK
```

注意：纯单目尺度任意；若为 `IMU_MONOCULAR`，尺度随后由 IMU 初始化修正。

## 4.3 正常跟踪（状态 OK）

```text
GrabImage* 构建 Frame（ORB + 立体/深度）
  → [IMU] PreintegrateIMU
  → 预测位姿：
        TrackWithMotionModel（恒速模型 + 投影匹配）
     或 TrackReferenceKeyFrame（BoW 匹配到参考 KF）
  → PoseOptimization / PoseInertialOptimization*
  → TrackLocalMap：
        UpdateLocalMap
        SearchLocalPoints（投影）
        再次 PoseOptimization*
  → NeedNewKeyFrame ?
        Yes → CreateNewKeyFrame → LocalMapping::InsertKeyFrame
  → 记录 mlRelativeFramePoses 等
```

失败分支：

```text
匹配不足
  → RECENTLY_LOST
       IMU：PredictStateIMU 维持短时
       视觉：Relocalization（KFDB + PnP/MLPnP）
  → 仍失败 → LOST
       地图过小：ResetActiveMap
       否则：CreateMapInAtlas（Multi-Map）
```

## 4.4 局部建图流水线

```text
新 KeyFrame 入队
  → ProcessNewKeyFrame
        计算 BoW
        关联 MapPoint 观测
        UpdateConnections（共视图）
        插入 Map / KFDB
  → MapPointCulling（观测不足/高 reprojection 的新点）
  → CreateNewMapPoints（邻接 KF 三角化）
  → SearchInNeighbors（Fuse 重复点）
  → LocalBundleAdjustment 或 LocalInertialBA
  → [惯性] InitializeIMU / ScaleRefinement
  → KeyFrameCulling（冗余 KF）
  → 交给 LoopClosing
```

## 4.5 回环检测与校正

```text
新 KF → KeyFrameDatabase 查询候选
  → DetectCommonRegionsFromBoW
  → Sim3 估计与投影匹配精炼
  → 连续 coincidence 确认 Loop
  → CorrectLoop：
        传播 Sim3 校正
        OptimizeEssentialGraph / 4DoF
        SearchAndFuse
        启动 Full BA / FullInertialBA（独立线程）
```

`mbFixScale`：双目/RGB-D（及带度量尺度的配置）固定尺度，Sim3 退化为 SE3；纯单目估计 7DoF。

## 4.6 地图融合（Map Merge）

触发：地点识别命中 **其他地图** 的关键帧。

```text
BoW 候选（跨地图）
  → Sim3：mSold_new
  → [惯性] 尺度/重力一致性检查
  → MergeLocal / MergeLocal2
        对齐坐标系
        Welding BA（焊接区局部优化）
        合并 KF / MP
        Atlas::ChangeMap
        旧地图 SetMapBad
```

典型应用：跟踪丢失后新建地图，稍后回到已知区域时无缝接回。

## 4.7 重定位

入口：`Tracking::Relocalization()`

```text
当前 Frame 计算 BoW
  → KFDB::DetectRelocalizationCandidates
  → 对候选 KF 做 BoW 匹配
  → MLPnP / PnP + RANSAC
  → 投影匹配扩展内点
  → PoseOptimization
  → 成功则恢复 OK
```

## 4.8 纯定位模式

`System::ActivateLocalizationMode()`：

- LocalMapping 停止接收/处理建图
- Tracking `mbOnlyTracking = true`
- 仍可跟踪与重定位；地图点不增长（或仅做临时 VO 点）

`DeactivateLocalizationMode()` 恢复完整 SLAM。
