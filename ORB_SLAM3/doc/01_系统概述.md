# 01 系统概述

## 1.1 项目定位

ORB-SLAM3（V1.0）是 Zaragoza 大学开源的实时 SLAM 系统，在 ORB-SLAM / ORB-SLAM2 基础上扩展为：

- **Visual SLAM**：单目 / 双目 / RGB-D
- **Visual-Inertial SLAM**：上述视觉配置 + IMU
- **Multi-Map SLAM（Atlas）**：会话内多地图管理与无缝融合

支持 **针孔** 与 **鱼眼（Kannala–Brandt）** 镜头模型。许可证为 **GPLv3**。

## 1.2 相对前代的主要能力

| 能力 | 说明 |
|------|------|
| 多地图 Atlas | Tracking 丢失后可新建地图；重访公共区域时 Merge |
| IMU 紧耦合 | 帧率预积分；约 2s 完成初始化（尺度误差通常 <5%），后续继续精炼 |
| 鱼眼相机 | 单目 / 双目均可使用原始鱼眼图像（无需强制去畸变到针孔） |
| 地图存取 | Boost 序列化保存/加载 Atlas（`.osa`） |
| 新配置格式 | `File.version: "1.0"`，支持在线双目矫正与图像缩放 |

V1.0 还将大量 OpenCV 静态矩阵替换为 Eigen，相对论文报告时间，跟踪约快 16%、建图约快 19%。

## 1.6 传感器枚举

定义于 `include/System.h`：

```cpp
enum eSensor {
    MONOCULAR = 0,
    STEREO = 1,
    RGBD = 2,
    IMU_MONOCULAR = 3,
    IMU_STEREO = 4,
    IMU_RGBD = 5,
};
```

| 模式 | Track API | 尺度 |
|------|-----------|------|
| MONOCULAR | `TrackMonocular` | 相对尺度 |
| STEREO / RGBD | `TrackStereo` / `TrackRGBD` | 度量尺度（基线/深度） |
| IMU_MONOCULAR | `TrackMonocular` + IMU | 初始化后估计尺度 |
| IMU_STEREO / IMU_RGBD | 对应视觉 API + IMU | 度量尺度 + 惯性约束 |

## 1.7 核心设计思想（一句话）

以 **ORB 特征 + DBoW2 地点识别 + 局部/全局 BA（g2o）** 为骨架，用 **Atlas** 管理多地图，用 **IMU 预积分** 增强短时运动估计与尺度可观性，在统一框架下覆盖视觉与视觉惯性场景。
