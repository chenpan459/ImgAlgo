# 06 配置与使用

## 6.1 配置文件格式

新格式以 YAML 字段标识：

```yaml
File.version: "1.0"
```

存在该字段时，由 `Settings`（`include/Settings.h`，`src/Settings.cc`）统一解析；否则走 `Tracking::Parse*ParamFile` 旧路径。

相机类型：

```yaml
Camera.type: "PinHole"        # 或 "Rectified" / "KannalaBrandt"
```

## 6.2 主要配置项

### 系统

```yaml
System.LoadAtlasFromFile: "my_atlas"   # 可选，无扩展名；实际读 ./.osa
System.SaveAtlasToFile: "my_atlas"     # Shutdown 时保存
System.thFarPoints: ...                # 远点阈值相关
loopClosing: 1                         # 是否启用回环（System 侧读取）
```

### 相机

```yaml
Camera1.fx / fy / cx / cy
Camera1.k1 / k2 / p1 / p2              # PinHole 畸变
# 鱼眼则使用 k1..k4（KannalaBrandt）
Camera2.*                              # 双目右目
Camera.width / height
Camera.newWidth / newHeight            # 可选缩放
Camera.fps
Camera.RGB                             # 1=RGB, 0=BGR
```

### 双目 / RGB-D

```yaml
Stereo.ThDepth: ...
Stereo.b: ...                          # 或 Stereo.T_c1_c2
RGBD.DepthMapFactor: ...
```

### IMU

```yaml
IMU.T_b_c1: !!opencv-matrix ...        # body ← camera1
IMU.NoiseGyro / NoiseAcc
IMU.GyroWalk / AccWalk
IMU.Frequency: 200.0
IMU.insertKFsWhenLost: ...             # 可选
```

### ORB

```yaml
ORBextractor.nFeatures: 1000
ORBextractor.scaleFactor: 1.2
ORBextractor.nLevels: 8
ORBextractor.iniThFAST: 20
ORBextractor.minThFAST: 7
```

### Viewer

```yaml
Viewer.KeyFrameSize / KeyFrameLineWidth / GraphLineWidth
Viewer.PointSize / CameraSize / CameraLineWidth
Viewer.ViewpointX/Y/Z/F
```

完整标定说明见源码根目录 `Calibration_Tutorial.pdf`。  
参考示例：`Examples/Monocular-Inertial/EuRoC.yaml`。

## 6.3 Examples 结构

```text
Examples/
  Monocular/           mono_euroc / kitti / tum / tum_vi / realsense_*.cc
  Stereo/              stereo_euroc / kitti / tum_vi / realsense_*.cc
  RGB-D/               rgbd_tum / realsense_D435i.cc
  Monocular-Inertial/  mono_inertial_euroc / tum_vi / realsense_*.cc
  Stereo-Inertial/     stereo_inertial_euroc / tum_vi / realsense_*.cc
  RGB-D-Inertial/      rgbd_inertial_realsense_D435i.cc
  Calibration/         RealSense 标定数据采集
Examples_old/
  ... 含 ROS 节点、MultiSession yaml
```

典型主程序模式：

```cpp
ORB_SLAM3::System SLAM(vocab, settings, ORB_SLAM3::System::IMU_MONOCULAR, true);
for (each frame) {
    // 准备图像与 IMU 测量
    SLAM.TrackMonocular(im, t, vImu);
}
SLAM.Shutdown();
SLAM.SaveTrajectoryEuRoC("CameraTrajectory.txt");
```

## 6.4 数据集运行要点

### EuRoC

1. 下载 ASL 格式序列。
2. 修改 `euroc_examples.sh` 中 `pathDatasetEuroc`。
3. 运行 `./euroc_examples` 或单条 example 可执行文件。
4. 评估：`evaluation/` 提供左相机系 GT；`./euroc_eval_examples` 计算 RMS ATE。

### TUM-VI

1. 下载并解压序列。
2. 修改 `tum_vi_examples.sh` 中路径。
3. 鱼眼配置使用 KannalaBrandt；GT 多在起终点房间，误差常反映终点漂移。

### RealSense 实时

`Examples/*/realsense_*.cc` 依赖 `realsense2`（CMake 自动检测）。

## 6.5 ROS（可选）

1. 将 `Examples/ROS` 加入 `ROS_PACKAGE_PATH`。
2. `./build_ros.sh`
3. 节点：`Mono` / `Mono_Inertial` / `Stereo` / `Stereo_Inertial` / `RGBD`

示例（Stereo-Inertial + EuRoC bag）：

```bash
roscore
rosrun ORB_SLAM3 Stereo_Inertial Vocabulary/ORBvoc.txt Examples/Stereo-Inertial/EuRoC.yaml true
rosbag play --pause V1_02_medium.bag \
  /cam0/image_raw:=/camera/left/image_raw \
  /cam1/image_raw:=/camera/right/image_raw \
  /imu0:=/imu
```

词袋加载完成后，在 rosbag 终端按空格开始播放。

## 6.6 地图序列化（Atlas）

实现位置：`System::SaveAtlas` / `LoadAtlas`（private）

| 项 | 说明 |
|----|------|
| 触发加载 | YAML `System.LoadAtlasFromFile` |
| 触发保存 | YAML `System.SaveAtlasToFile`，在 `Shutdown()` 时写入 |
| 文件 | `./{name}.osa` |
| 格式 | Boost text/binary archive |
| 内容 | 词袋文件名 + checksum + `Atlas*` |
| 校验 | 词袋 checksum 必须一致，否则拒绝加载 |

`PreSave`/`PostLoad` 负责指针与 ID 互转；相关工具在 `SerializationUtils.h`。

`System.h` 中公开的 `SaveMap/LoadMap` 仍为 TODO 注释；实际请用 Atlas `.osa` 机制。

多会话思路：

```text
加载旧 Atlas → CreateNewMap → 跑新序列 → Place Recognition Merge
```

`Examples_old` 中 MultiSession 配置可作为参考。

## 6.7 轨迹输出格式

| API | 适用 |
|-----|------|
| `SaveTrajectoryTUM` | 双目/RGB-D 帧轨迹 |
| `SaveKeyFrameTrajectoryTUM` | 全传感器关键帧轨迹 |
| `SaveTrajectoryEuRoC` / `SaveKeyFrameTrajectoryEuRoC` | EuRoC 格式 |
| `SaveTrajectoryKITTI` | 双目/RGB-D |

均应先调用 `Shutdown()`。

## 6.8 评估脚本

`evaluation/`：

- `associate.py`：时间戳关联
- `evaluate_ate_scale.py`：ATE（可含尺度）
- `Ground_truth/`：EuRoC IMU / 左相机系真值

## 6.9 构建命令摘要

```bash
cd ORB_SLAM3-1.0-release
chmod +x build.sh
./build.sh
# 可选 ROS
chmod +x build_ros.sh
./build_ros.sh
```

前置：OpenCV、Eigen3、Pangolin；可选 realsense2、ROS。
