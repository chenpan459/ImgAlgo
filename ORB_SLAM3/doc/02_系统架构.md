# 02 系统架构

## 2.1 线程模型

| 线程 | 入口函数 | 宿主 | 职责 |
|------|----------|------|------|
| Tracking | `Tracking::Track()` | 主线程（调用方） | 特征提取、位姿估计、关键帧判定、重定位 |
| LocalMapping | `LocalMapping::Run()` | `mptLocalMapping` | 局部地图维护、三角化、LBA、IMU 初始化 |
| LoopClosing | `LoopClosing::Run()` | `mptLoopClosing` | 地点识别、回环校正、地图融合 |
| Viewer（可选） | `Viewer::Run()` | `mptViewer` | Pangolin 可视化 |
| Global BA（按需） | `LoopClosing::RunGlobalBundleAdjustment()` | `mpThreadGBA` | 回环后全图 BA |

`System` 构造时创建对象并 `Set*` 互连指针，然后启动后台线程。Tracking **不单独起线程**，由外部循环调用 `System::Track*`。

```text
                  ┌─────────────┐
   Image(+IMU)───►│   System    │
                  └──────┬──────┘
                         │ Track*
                         ▼
                  ┌─────────────┐     InsertKF      ┌──────────────┐
                  │  Tracking   │──────────────────►│ LocalMapping │
                  └──────┬──────┘                   └──────┬───────┘
                         │                                 │ InsertKF
                         │                                 ▼
                         │                          ┌──────────────┐
                         │                          │ LoopClosing  │──► GBA thread
                         │                          └──────┬───────┘
                         │                                 │
                         ▼                                 ▼
                  ┌─────────────────────────────────────────────┐
                  │                   Atlas                      │
                  │   Map(current) + Map(stored) + Cameras       │
                  └─────────────────────────────────────────────┘
```

## 2.2 System 入口

文件：`include/System.h`，`src/System.cc`

### 构造

```text
System(strVocFile, strSettingsFile, eSensor, bUseViewer=true, initFr=0, strSequence="")
```

主要步骤：

1. 解析 YAML：若 `File.version == "1.0"` 则走 `Settings`，否则 legacy 解析。
2. 加载 `ORBVocabulary`（文本词袋）。
3. 创建 `KeyFrameDatabase` 与 `Atlas`（或从文件 `LoadAtlas`）。
4. IMU 模式调用 `Atlas::SetInertialSensor()`。
5. 创建 `FrameDrawer` / `MapDrawer` / `Tracking` / `LocalMapping` / `LoopClosing` / `Viewer`。
6. 启动 LocalMapping、LoopClosing、Viewer 线程。

### 对外 Track API

```cpp
Sophus::SE3f TrackStereo(imL, imR, t, vImu=[], filename="");
Sophus::SE3f TrackRGBD(im, depth, t, vImu=[], filename="");
Sophus::SE3f TrackMonocular(im, t, vImu=[], filename="");
```

- 输入图像可为 RGB 或灰度；RGB 会转灰度。
- 成功返回相机位姿 `Sophus::SE3f`；失败返回空位姿。
- IMU 测量以 `vector<IMU::Point>` 可选传入。

### 生命周期与模式

| API | 作用 |
|-----|------|
| `ActivateLocalizationMode` / `DeactivateLocalizationMode` | 仅定位 / 恢复建图 |
| `Reset` / `ResetActiveMap` | 清空 Atlas 或仅当前地图 |
| `Shutdown` | 请求各线程结束并等待 |
| `ChangeDataset` | 多序列切换 |
| `SaveTrajectoryTUM/EuRoC/KITTI` | 导出轨迹 |
| `SaveKeyFrameTrajectory*` | 导出关键帧轨迹 |
| `GetTrackingState` / `GetTrackedMapPoints` | 查询最新跟踪状态 |

地图保存/加载实际通过私有方法 `SaveAtlas` / `LoadAtlas`，由 YAML 中 `System.SaveAtlasToFile` / `System.LoadAtlasFromFile` 触发（见配置文档）。

## 2.3 数据层级

```text
Image (+ IMU)
  → Frame                 # 瞬时观测
  → KeyFrame              # 持久关键帧（进入地图）
  → MapPoint              # 3D 路标
  → Map                   # 单张地图
  → Atlas                 # 多地图容器 + 相机库
```

| 类 | 文件 | 职责 |
|----|------|------|
| `Frame` | `Frame.h/.cc` | 当前帧 ORB、BoW、位姿、IMU 状态与预积分 |
| `KeyFrame` | `KeyFrame.h/.cc` | 共视图、生成树、回环/融合边、IMU 预积分 |
| `MapPoint` | `MapPoint.h/.cc` | 3D 点、观测、描述子、替换关系 |
| `Map` | `Map.h/.cc` | KF/MP 集合、IMU BA 阶段标志、互斥锁 |
| `Atlas` | `Atlas.h/.cc` | 多 Map、当前 Map、相机列表、序列化 |

关系要点：

- `Frame.mvpMapPoints[i]` 与第 i 个关键点关联。
- `KeyFrame(Frame&, Map*, KeyFrameDatabase*)` 由帧升级而来。
- `MapPoint::mObservations` 为 `map<KeyFrame*, tuple<leftIdx,rightIdx>>`。
- 运行时位姿多用 `Sophus::SE3f`；回环/融合估计用 `g2o::Sim3`。

## 2.4 Atlas 多地图

文件：`include/Atlas.h`，`src/Atlas.cc`

核心成员：

- `mspMaps`：存活地图集合
- `mpCurrentMap`：当前活动地图
- `mvpCameras`：`Pinhole` / `KannalaBrandt8` 相机实例
- IMU 标志：`SetInertialSensor` / `SetImuInitialized` / `isImuInitialized`

关键操作：

| 方法 | 行为 |
|------|------|
| `CreateNewMap()` | 归档当前 Map，新建空 Map |
| `ChangeMap(Map*)` | 切换活动地图（融合后常用） |
| `SetMapBad` / `RemoveBadMaps` | 标记并清理无效地图 |
| `PreSave` / `PostLoad` | 序列化前后指针↔ID 重建 |

Tracking 丢失后的策略（概念上）：

- 当前地图关键帧很少 → `ResetActiveMap()`
- 否则 → `CreateMapInAtlas()`，旧地图保留，等待后续 Merge

## 2.5 线程同步要点

| 机制 | 作用 |
|------|------|
| `Map::mMutexMapUpdate` | Tracking 持锁执行 `Track()`；建图/回环改图时同样加锁 |
| `LocalMapping::mbAcceptKeyFrames` | 背压：忙时拒绝新关键帧 |
| `LocalMapping::mbAbortBA` | 新关键帧到达时打断 LBA |
| `KeyFrame::SetNotErase` | LoopClosing 处理期间防止被剔除 |
| 各模块 `RequestStop/Reset/Finish` | 协作式停止与重置 |

关键帧路径：

```text
Tracking::CreateNewKeyFrame()
  → LocalMapping::InsertKeyFrame()
  →（处理完毕）LoopClosing::InsertKeyFrame()
```

## 2.6 组件关系总览

```text
System
 ├─ ORBVocabulary
 ├─ KeyFrameDatabase
 ├─ Atlas ── Map* / GeometricCamera* / Voc / KFDB
 ├─ Tracking ── Frame, ORBextractor*, IMU queue
 ├─ LocalMapping
 ├─ LoopClosing ── (optional) GBA thread
 ├─ Viewer / FrameDrawer / MapDrawer
 └─ Settings*
```
