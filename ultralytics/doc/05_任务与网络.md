## 5.2 YOLO26 网络 YAML

示例：`cfg/models/26/yolo26.yaml`

```yaml
nc: 80
end2end: True
reg_max: 1
scales:
  n: [0.50, 0.25, 1024]
  s: [0.50, 0.50, 1024]
  # m / l / x ...
backbone:
  - [-1, 1, Conv, [64, 3, 2]]
  - [-1, 2, C3k2, [256, False, 0.25]]
  - [-1, 1, SPPF, [1024, 5, 3, True]]
  - [-1, 2, C2PSA, [1024]]
  # ...
head:
  # Upsample + Concat + C3k2 构成 FPN/PAN 风格 neck
  - [[16, 19, 22], 1, Detect, [nc]]
```

同目录变体：`yolo26-seg/pose/obb/cls/sem/depth/p2/p6.yaml`、`yoloe-26.yaml` 等。

历史架构仍保留：`cfg/models/{v3,v5,v6,v8,v9,v10,11,12,rt-detr}/`。

## 5.3 parse_model 流程

文件：`nn/tasks.py` → `parse_model(d, ch)`

```text
读 nc, scales, end2end, reg_max, depth_multiple, width_multiple
→ 按 scale 调整通道与深度
→ 遍历 backbone + head 层定义:
     [from, repeats, module_name, args]
→ getattr(modules, module_name)(...) 或 nn.* 
→ 组装 nn.Sequential + save 索引列表
→ 返回 model, save
```

`BaseModel._predict_once` 按每层 `m.f`（from）从缓存取输入，支持跨层 Concat。

## 5.4 检测头要点

`nn/modules/head.py`：

| Head | 用途 |
|------|------|
| `Detect` | 标准/端到端检测 |
| `Segment` / `Segment26` | 实例分割 + Proto |
| `Pose` / `Pose26` | 关键点 |
| `OBB` / `OBB26` | 旋转框 |
| `Depth` | 深度 |
| `Classify` | 分类 |
| `SemanticSegment` | 语义分割 |
| `WorldDetect` / `YOLOEDetect` / `YOLOESegment*` | 开放词汇 |
| `RTDETRDecoder` | RT-DETR |
| `v10Detect` | YOLOv10 遗留 |

YOLO26：`end2end=True`、`reg_max=1`，损失侧配合 `E2EDetectLoss`、`PoseLoss26`、`DepthLoss26` 等（`utils/loss.py`）。

## 5.5 常用 Backbone / Neck 模块

来自 `nn/modules/block.py`、`conv.py`：

| 模块 | 角色 |
|------|------|
| `Conv` | 标准卷积块 |
| `C3k2` | YOLO26 常用 CSP 变体 |
| `C2f` | YOLOv8 风格块（历史模型） |
| `C2PSA` | 注意力增强 |
| `SPPF` | 空间金字塔池化 |
| `A2C2f` / `PSA` | 注意力/特征增强 |
| `Proto` / `Proto26` | 分割原型 mask |
| `DFL` | Distribution Focal Loss 解码（reg_max>1 时） |

## 5.6 损失与匹配

| 组件 | 路径 | 说明 |
|------|------|------|
| TAL | `utils/tal.py` | Task-Aligned Assigner 正负样本分配 |
| Detection loss | `v8DetectionLoss` / `E2EDetectLoss` | box/cls/dfl |
| Segment / Pose / OBB | 对应 `v8*Loss` / `*26` | 附加 mask/kpt/angle 项 |
| Depth / Semantic | `DepthLoss26` / `SemanticSegmentationLoss` | 密集预测损失 |

超参见 `default.yaml`：`box`、`cls`、`dfl`、`pose`、`angle` 等权重。
