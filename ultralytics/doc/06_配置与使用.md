# 06 配置与使用

## 6.1 配置体系

| 来源 | 路径/位置 | 作用 |
|------|-----------|------|
| 全局默认 | `cfg/default.yaml` | 全部 train/val/predict/export 参数 |
| 模型结构 | `cfg/models/**/*.yaml` | backbone/head |
| 数据集 | `cfg/datasets/*.yaml` | path/train/val/names |
| 跟踪器 | `cfg/trackers/*.yaml` | ByteTrack/BoT-SORT… |
| 用户设置 | `~/.config/Ultralytics/settings.json` | 目录与 API Key |
| 运行时覆盖 | CLI `arg=value` 或 Python kwargs | 最高优先级之一 |

合并入口：`get_cfg(cfg, overrides)`；废弃参数由 `_handle_deprecation` 迁移。

## 6.2 default.yaml 分区（摘要）

### Train

```yaml
epochs: 100
batch: 16              # 或 0.0–1.0 表示 AutoBatch 显存比例
imgsz: 640
device:                # 0 / [0,1] / cpu / mps / -1
optimizer: auto        # SGD, MuSGD, AdamW, ...
amp: True
compile: False
channels_last: False
close_mosaic: 10
patience: 100
pretrained: True
cls_remap: True
freeze:
multi_scale: 0.0
distill_model:         # 可选蒸馏教师
```

### Val / Predict

```yaml
conf:                  # predict 默认约 0.25；val 约 0.001
iou: 0.7
max_det: 300
quantize:              # 16/fp16, 8/int8, ...；替代 half/int8
plots: True
save_json: False
retina_masks: False
end2end:               # 与模型 YAML 呼应
```

### Export

```yaml
format: torchscript
dynamic: False
simplify: True
opset:
workspace:
nms: False
```

### Hyp（增强与损失权重）

```yaml
lr0 / lrf / momentum / weight_decay / warmup_*
box / cls / dfl / pose / angle / ...
hsv_h / hsv_s / hsv_v
degrees / translate / scale / shear / perspective
flipud / fliplr / mosaic / mixup / cutmix / copy_paste
```

### Tracker

```yaml
tracker: tracktrack.yaml   # 默认
```

完整注释见源码 `ultralytics/cfg/default.yaml`。

## 6.3 数据集 YAML 示例

  0: person

任务小样：`coco8.yaml`、`coco8-seg.yaml`、`coco8-pose.yaml`、`dota8.yaml`、`cityscapes8.yaml`、`depth8.yaml`。

## 6.4 Python API

```python
from ultralytics import YOLO

model = YOLO("yolo26n.pt")                 # 或 yolo26n.yaml 从头建
model.train(data="coco8.yaml", epochs=100, imgsz=640, device=0)
metrics = model.val()
results = model("bus.jpg")                 # predict
results[0].show()
model.track(source="video.mp4", tracker="bytetrack.yaml")
path = model.export(format="onnx", dynamic=True, quantize=16)
model.benchmark(data="coco8.yaml")
```

开放词汇示例：

```python
from ultralytics import YOLOWorld
model = YOLOWorld("yolov8s-world.pt")
model.set_classes(["person", "bus", "helmet"])
model.predict("bus.jpg")
```

## 6.5 CLI

语法：`yolo [TASK] MODE [ARGS]`

```bash
# 训练 / 验证 / 预测 / 导出 / 跟踪 / 基准
yolo train data=coco8.yaml model=yolo26n.pt epochs=10 lr0=0.01
yolo val model=yolo26n.pt data=coco8.yaml
yolo predict model=yolo26n-seg.pt source=bus.jpg imgsz=320
yolo export model=yolo26n.pt format=onnx imgsz=640
yolo track model=yolo26n.pt source=video.mp4 tracker=bytetrack.yaml
yolo benchmark model=yolo26n.pt data=coco8.yaml

# Solutions
yolo solutions count source=video.mp4
yolo streamlit-predict

# 工具
yolo cfg
yolo version
yolo checks
yolo settings
yolo hub login
yolo copy-cfg
```

`entrypoint` 按模型 stem 分发：`rtdetr*`→`RTDETR`，`fastsam*`→`FastSAM`，`sam_*`/`sam2*`/`sam3*`→`SAM`，否则 `YOLO`。

## 6.6 导出格式表（摘要）

`export_formats()` 支持的 `format` 参数包括：

| format | 产物后缀/目录（示意） |
|--------|------------------------|
| torchscript | `.torchscript` |
| onnx | `.onnx` |
| openvino | `*_openvino_model/` |
| engine | `.engine`（TensorRT） |
| coreml | `.mlpackage` |
| saved_model / pb | TF SavedModel / GraphDef |
| edgetpu | Edge TPU tflite |
| paddle / mnn / ncnn | 对应目录/文件 |
| imx / rknn / executorch | 边缘平台 |
| axelera / deepx / qnn / litert / hailo / ascend | 更多边缘后端 |

精度：`quantize=16|8|"w8a16"|"w8a32"|32`；不同 format 支持集合不同（见 `exporter.py` 中 `FP16_FORMATS` / `INT8_FORMATS`）。

可选依赖 extras：`export-base`、`export-tensorflow`、`export-coreml`、`export-litert`、`export-executorch` 等。

## 6.7 常见运行产物
