# 01 系统概述

## 1.1 项目定位

**Ultralytics**（PyPI 包名 `ultralytics`）是 YOLO 家族官方统一框架，覆盖：

- 目标检测（detect）
- 实例分割（segment）
- 语义分割（semantic）
- 图像分类（classify）
- 姿态估计（pose）
- 旋转框检测（obb）
- 深度估计（depth）
- 多目标跟踪（track）
- 约 20 种部署格式导出（export）
- 端侧/云端应用方案（solutions）

本分析版本：`8.4.107`（`ultralytics/__init__.py`）。  
运行底线：Python ≥ 3.8，PyTorch ≥ 1.8。  
许可证：**AGPL-3.0**（商业用途需企业许可）。

## 1.2 8.4 / YOLO26 相对早期 8.x 的要点

| 要点 | 说明 |
|------|------|
| 默认模型 | 从 YOLOv8/YOLO11 示例切到 **YOLO26**（`yolo26n.pt`） |
| 新任务 | `semantic`（如 Cityscapes mIoU）、`depth`（如 NYU δ1，含 `calibrate()`） |
| YOLO26 Head | `end2end: True`，`reg_max: 1`；配套 Segment26/Pose26/OBB26 等 |
| 导出精度 API | 统一用 `quantize`（替代废弃的 `half`/`int8`） |
| 跟踪器 | 默认 `tracktrack.yaml`；新增 OC-SORT / DeepOC-SORT / FastTrack 等 |
| 优化器 | `optimizer: auto` 可含 **MuSGD**（`optim/muon.py`） |
| 训练增强 | `compile`、`channels_last`、`distill_model`、多数据集 `MultiTrainer` |
| 导出后端 | Hailo / Ascend / QNN / DeepX / LiteRT / ExecuTorch 等边缘格式 |
| 包导入 | 顶层模型类 **懒加载**（`__getattr__`），加快 `import ultralytics` |

## 1.3 仓库目录结构

```text
ultralytics-8.4.107/
├── ultralytics/           # 主 Python 包
│   ├── engine/            # Model / Trainer / Validator / Predictor / Exporter
│   ├── models/            # yolo / rtdetr / sam / fastsam / nas
│   ├── nn/                # tasks、modules、backends
│   ├── data/              # 数据集、增强、loaders
│   ├── cfg/               # default.yaml、模型/数据集/跟踪器 YAML、CLI
│   ├── utils/             # loss、metrics、ops、callbacks、export

│   ├── solutions/         # 计数、热力图、停车等应用
│   ├── hub/               # Ultralytics HUB
│   ├── optim/             # MuSGD 等
│   └── assets/            # 示例图片
├── examples/              # 示例脚本 / notebook
├── tests/                 # pytest

├── docker/                # Docker 相关

├── README.md / README.zh-CN.md

```

## 1.5 安装与快速验证

```bash
# 包安装
pip install ultralytics
# 或源码可编辑安装
cd ultralytics-8.4.107
pip install -e ".[dev,export-base,solutions]"

# 最快端到端冒烟（自动下载 yolo26n.pt）
yolo predict model=yolo26n.pt
```

Python：

```python
from ultralytics import YOLO

model = YOLO("yolo26n.pt")
results = model("ultralytics/assets/bus.jpg")
results[0].show()
```

## 1.7 核心设计思想（一句话）

以 **`Model` 统一门面 + `task_map` 任务四元组** 组织代码：YAML/`parse_model` 构建网络，`default.yaml` 驱动超参，Engine 负责 train/val/predict/export 生命周期，Trackers/Solutions/Exporter 覆盖跟踪、应用与部署。
