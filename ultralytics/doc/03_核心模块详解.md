# 03 核心模块详解

## 3.1 Engine

路径：`ultralytics/engine/`

### BaseTrainer（`trainer.py`）

生命周期：

1. `__init__`：合并 `DEFAULT_CFG` 与 overrides，解析 data/device
2. `train()`：多卡走 DDP 子进程，否则 `_do_train()`
3. `_setup_train()`：`setup_model` → freeze → AMP → compile → DDP → AutoBatch → dataloader / optimizer / scheduler → EMA → EarlyStopping
4. `_do_train()`：epoch 循环 → warmup → forward/loss → `optimizer_step` → validate → `save_model` → `close_mosaic`
5. `final_eval()`：最佳权重终验

任务子类需覆盖：`build_dataset`、`get_dataloader`、`get_model`、`get_validator`、`preprocess_batch`、`set_model_attributes`。

`MultiTrainer`：`data=["a.yaml","b.yaml"]` 时串行微调并汇总 metrics。

### BaseValidator（`validator.py`）

`__call__(trainer|model)`：

```text
建 dataloader → init_metrics
→ batch: preprocess → infer → postprocess → update_metrics
→ finalize_metrics / get_stats / print_results
```

可选 `save_json` 导出 COCO JSON 等。

### BasePredictor（`predictor.py`）

```text
setup_model(AutoBackend)
→ setup_source(load_inference_source)
→ stream_inference:
     preprocess → inference → postprocess → Results
     → 可选 show / save
```

CLI 用 `predict_cli`；Python API 用 `__call__(stream=...)`。

### Exporter（`exporter.py`）

`__call__(model)`：

1. 解析 `format`（`export_formats()`）
2. dummy input、fuse、可选 NMS 包装
3. 调用 `export_{fmt}()`（多数格式先 ONNX 再转换）
4. 触发 export 回调，返回路径

### Results（`results.py`）

| 类 | 用途 |
|----|------|
| `Results` | 单帧容器：`boxes/masks/keypoints/probs/obb/speed/names` |
| `Boxes` / `Masks` / `Keypoints` / `Probs` / `OBB` | 检测相关张量包装 |
| `SemanticMask` / `DepthMap` | 语义 / 深度 |
| `BaseTensor` | xyxy/xywh/cpu/numpy/cuda 统一接口 |

### Tuner（`tuner.py`）

超参搜索（内置或配合 Ray Tune）。

## 3.2 Models

路径：`ultralytics/models/`

### YOLO 任务子包

```text
models/yolo/
  detect/ segment/ pose/ classify/ obb/ semantic/ depth/
  world/ yoloe/
  model.py   # YOLO / YOLOWorld / YOLOE
```

每个任务目录通常含：`train.py`、`val.py`、`predict.py`（depth 另有 `calibrate.py`）。

### 其他架构家族

| 类 | 路径 | 说明 |
|----|------|------|
| `RTDETR` | `models/rtdetr/` | Transformer 检测；`RTDETRDetectionModel` + `RTDETRDecoder` |
| `SAM` | `models/sam/` | SAM / SAM2 / SAM3 |
| `FastSAM` | `models/fastsam/` | 快速分割；bbox/point/text prompt |
| `NAS` | `models/nas/` | 依赖 `super_gradients`；权重 `.pt` |
| `YOLOWorld` | `models/yolo/model.py` | 开放词汇；`set_classes` |
| `YOLOE` | 同上 | 文本/视觉 prompt；`get_text_pe` / `set_vocab` 等 |

## 3.3 NN

路径：`ultralytics/nn/`

### tasks.py

模型继承关系（概念）：

```text
BaseModel
 ├─ DetectionModel → OBBModel / SegmentationModel / PoseModel / DepthModel
 ├─ ClassificationModel
 ├─ SemanticSegmentationModel
 ├─ RTDETRDetectionModel
 ├─ WorldModel
 └─ YOLOEModel / YOLOESegModel
```

- `BaseModel.forward`：输入 dict → `loss()`；tensor → `predict()` / `_predict_once`
- `parse_model(d, ch)`：解析 YAML `backbone+head`，按 `[from, repeats, module, args]` 实例化层
- 工具：`yaml_model_load`、`guess_model_task`、`guess_model_scale`、`load_checkpoint`

### modules/

| 文件 | 内容 |
|------|------|
| `conv.py` | Conv、Concat 等基础层 |
| `block.py` | C2f、C3k2、C2PSA、SPPF、A2C2f、Proto… |
| `head.py` | Detect、Segment、Pose、OBB、Depth、Classify、YOLOE*、RTDETRDecoder、SemanticSegment… |
| `transformer.py` | AIFI、MSDeformAttn 等 |
| `activation.py` / `utils.py` | 激活与辅助 |

### backends / AutoBackend

`nn/autobackend.py` + `nn/backends/`：统一加载 PyTorch、TorchScript、ONNX、TensorRT、OpenVINO、CoreML、TF、Paddle、NCNN、MNN、RKNN、IMX、ExecuTorch、Hailo、Ascend、QNN、LiteRT、Triton 等。

另：`nn/distill_model.py`（蒸馏）、`nn/text_model.py`（CLIP/文本，供 YOLOE/World/Solutions）。

## 3.6 Solutions

路径：`ultralytics/solutions/`

基类：`BaseSolution`（加载 YOLO、跟踪、区域几何、`process()`）。

CLI `SOLUTION_MAP` 映射（节选）：

| CLI 键 | 类 |
|--------|-----|
| count | `ObjectCounter` |
| crop / blur | `ObjectCropper` / `ObjectBlurrer` |
| workout | `AIGym` |
| heatmap | `Heatmap` |
| isegment | `InstanceSegmentation` |
| speed | `SpeedEstimator` |
| queue | `QueueManager` |
| parking / security | `ParkingManagement` / `SecurityAlarm` |
| region / trackzone | `RegionCounter` / `TrackZone` |
| inference | `Inference`（Streamlit） |

用法：`yolo solutions count source=video.mp4 region="[(x,y),...]"`。
