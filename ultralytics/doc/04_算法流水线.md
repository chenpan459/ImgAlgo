# 04 算法流水线

## 4.1 Train

```text
YOLO("yolo26n.pt").train(data="coco8.yaml", epochs=100, imgsz=640, device=0)
  → Model.train()
  → DetectionTrainer (task_map)
  → check_det_dataset / get_dataset
  → get_model(DetectionModel) + 加载预训练
  → _setup_train (AMP/DDP/AutoBatch/优化器/EMA)
  → _do_train:
        for epoch:
          for batch:
            preprocess_batch
            preds = model(batch)
            loss = criterion(preds, batch)
            backward + optimizer_step
          validator()          # 验证
          save_model()         # last.pt / best.pt
          close_mosaic?        # 最后 N epoch 关闭 mosaic
  → final_eval
  → 返回 metrics；Model 可 reload best/last
```

产出目录（默认）：`runs/detect/train*/`  
含：`weights/best.pt`、`weights/last.pt`、`results.csv`、曲线图、混淆矩阵等。

多数据集：`data=["ds1.yaml","ds2.yaml"]` → `MultiTrainer` 串行微调。

## 4.2 Val

```text
model.val(data="coco8.yaml", split="val")
  → DetectionValidator
  → dataloader → preprocess → infer → postprocess
  → update_metrics (mAP / mIoU / delta1 / accuracy …)
  → finalize_metrics / print_results
  → model.metrics
```

训练中每个 epoch 也会调用 Validator（`val=True`）。

## 4.3 Predict

```text
model.predict(source, stream=False, conf=0.25, imgsz=640)
  # 或 model(source)
  → DetectionPredictor.setup_model(AutoBackend)
  → load_inference_source(source)   # 图/视频/webcam/URL/tensor
  → stream_inference:
        LetterBox / 归一化
        model forward
        NMS / 任务后处理
        构造 Results
        可选 save/show/crop
  → list[Results] 或 generator(stream=True)
```

`Results` 常用：`boxes`、`masks`、`keypoints`、`obb`、`probs`、`plot()`、`save()`、`tojson()`。

## 4.4 Track

```text
model.track(source=video, tracker="bytetrack.yaml", persist=True)
  → register_tracker(model)
  → 内部调用 predict（默认 conf≈0.1, batch=1）
  → on_predict_postprocess_end: 关联轨迹 ID
  → Results.boxes.id
```

可切换 tracker YAML：`bytetrack` / `botsort` / `tracktrack` / `ocsort` / `deepocsort` / `fasttrack`。

## 4.5 Export

```text
model.export(format="onnx", dynamic=True, simplify=True, quantize=16)
  → Exporter(overrides).__call__(model)
  → fuse + 可选 ExportWrapper/NMSModel
  → export_onnx / export_engine / …
  → 返回导出路径 str
```

典型再推理：

```python
exported = YOLO("yolo26n.onnx")  # AutoBackend
exported.predict(source)
```

精度参数统一用 `quantize`：`16`/`fp16`、`8`/`int8`、`w8a8`/`w8a16`/`w8a32` 等；旧参数 `half`/`int8` 会经 deprecation 迁移。

## 4.6 Benchmark

```text
model.benchmark(data="coco8.yaml", imgsz=640)
  # 或 yolo benchmark model=yolo26n.pt
  → utils.benchmarks.benchmark
  → 对各 export 格式测速度与精度（受环境依赖影响）
```

## 4.7 Tune

```text
model.tune(data="coco8.yaml", iterations=300)
  → Ray Tune 或 engine.tuner.Tuner
  → 搜索 lr0、augment 等超参
```

## 4.8 Depth 标定

```text
model = YOLO("yolo26n-depth.pt")
model.calibrate(...)   # 拟合 cal_a / cal_b
```

仅 depth 任务；用于将网络输出映射到度量深度。

## 4.9 Solutions 流水线

```text
yolo solutions count source=video.mp4
  → entrypoint → SOLUTION_MAP["count"] → ObjectCounter
  → BaseSolution: 加载 YOLO + tracker + 区域几何
  → 逐帧 process() → 可视化 / 统计输出
```
