# 各示例所需基础知识

说明：每个 demo 列出 **前置 Demo**、**编程/数学基础**、**图像概念**、**本课核心 API**。  
建议严格按编号推进；跳级时至少补齐「前置 Demo」。

---

## 通用基础（所有例子共用）

| 类别 | 需要掌握 |
|------|----------|
| C++ | 基本语法、`main`、`#include`、`std::vector`、读写文件路径 |
| 工具 | CMake / `./build.sh`、终端运行、查看 `output/` 图片 |
| 图像常识 | 像素、宽高、通道；OpenCV 默认 **BGR**（不是 RGB） |
| 坐标 | 图像原点在左上，`x` 向右、`y` 向下 |
| Mat 直觉 | `Mat` 是图像/矩阵容器；`empty()`、`cols/rows/channels` |

## 入门（01–10）

### 01_hello_image — 读图 / 存图 / 灰度

| 项 | 内容 |
|----|------|
| 前置 Demo | 无 |
| 编程 | C++ 编译运行 |
| 图像概念 | 位图、灰度 vs 彩色、文件格式（png/jpg） |
| 核心 API | `imread` `imwrite` `cvtColor` `COLOR_BGR2GRAY` |
| 学完应会 | 解释 BGR 三通道；会把结果保存到磁盘 |

### 02_mat_roi — Mat 与 ROI

| 项 | 内容 |
|----|------|
| 前置 Demo | 01 |
| 编程 | 嵌套循环、引用 vs 拷贝的直觉 |
| 数学 | 矩形区域 `(x,y,w,h)` |
| 图像概念 | 连续内存、子矩阵共享数据 |
| 核心 API | `Mat` 构造、`at<Vec3b>`、`ptr`、`Rect`、`clone`、`copyTo` |
| 学完应会 | 说清 ROI 修改为何会影响原图 |

### 03_color_space — 颜色空间与阈值

| 项 | 内容 |
|----|------|
| 前置 Demo | 01–02 |
| 数学 | 阈值、区间 `[low, high]` |
| 图像概念 | BGR / Gray / HSV；H 色相、S 饱和度、V 亮度 |
| 核心 API | `cvtColor` `split` `inRange` `copyTo(mask)` |
| 学完应会 | 用 HSV 抠出某种颜色 |

### 04_drawing — 绘图

| 项 | 内容 |
|----|------|
| 前置 Demo | 01–02 |
| 几何 | 点、线、圆、矩形、多边形 |
| 核心 API | `line` `rectangle` `circle` `ellipse` `polylines` `putText` `arrowedLine` |
| 学完应会 | 在图上标注检测结果 |

### 05_filter — 滤波去噪

| 项 | 内容 |
|----|------|
| 前置 Demo | 01、03 |
| 数学 | 均值、卷积核大小（奇数）、高斯分布直觉 |
| 图像概念 | 噪声、模糊、保边滤波 |
| 核心 API | `blur` `GaussianBlur` `medianBlur` `bilateralFilter` |
| 学完应会 | 根据噪声类型选滤波 |

### 06_edge — 边缘检测

| 项 | 内容 |
|----|------|
| 前置 Demo | 05（先平滑再边缘） |
| 数学 | 梯度、偏导数直觉；双阈值 |
| 图像概念 | 边缘 = 强度剧变处 |
| 核心 API | `Sobel` `Laplacian` `Canny` `convertScaleAbs` |
| 学完应会 | 调节 Canny 高低阈值看效果 |

### 07_morphology — 形态学

| 项 | 内容 |
|----|------|
| 前置 Demo | 03 或 06（需要二值图） |
| 数学 | 集合膨胀/腐蚀直觉 |
| 图像概念 | 结构元素、开运算去噪、闭运算补洞 |
| 核心 API | `threshold` `getStructuringElement` `erode` `dilate` `morphologyEx` |
| 学完应会 | 用开闭运算清理二值掩膜 |

### 08_contour — 轮廓与形状特征

| 项 | 内容 |
|----|------|
| 前置 Demo | 06–07 |
| 数学 | 面积、周长、矩（重心）、多边形逼近 |
| 图像概念 | 连通边界、外接矩形 / 最小外接矩形 |
| 核心 API | `findContours` `drawContours` `boundingRect` `minAreaRect` `moments` `approxPolyDP` |
| 学完应会 | 过滤小轮廓并画框 |

### 09_geometry — 几何变换

| 项 | 内容 |
|----|------|
| 前置 Demo | 01–02、04 |
| 数学 | 2D 变换：缩放、旋转、仿射（6DoF）、透视（单应性直觉） |
| 核心 API | `resize` `flip` `getRotationMatrix2D` `warpAffine` `getPerspectiveTransform` `warpPerspective` |
| 学完应会 | 旋转图像；用四点做透视拉正雏形 |

### 10_feature_match — ORB 特征匹配

| 项 | 内容 |
|----|------|
| 前置 Demo | 06、09 |
| 数学 | 距离（Hamming）、最近邻匹配 |
| 图像概念 | 关键点、描述子、匹配连线 |
| 核心 API | `ORB::create` `detectAndCompute` `BFMatcher` `drawMatches` `drawKeypoints` |
| 学完应会 | 解释为何旋转后仍能匹配 |

## 速查：按主题缺什么补什么

| 你卡在… | 先补这些 Demo / 知识 |
|---------|----------------------|
| Mat 改了原图 | 02（ROI/clone） |
| 颜色选不出来 | 03（HSV） |
| 边缘乱 | 05→06（先模糊） |
| 轮廓碎 | 07→08 |
| 匹配不准 | 10→14（RANSAC） |
